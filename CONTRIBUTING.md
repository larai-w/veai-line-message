# Contributing to veai-line-message

Contributions are welcome. This repository is public.
Do not commit private strategy, raw care data, credentials, or personal details.

## How to start

- For first-time contributors: open an issue with the **Good first issue** template.
- For change requests: open issues and link pull requests from compare mode.

Before starting, check [open starter tasks](https://github.com/larai-w/veai-line-message/issues?q=is%3Aissue%20is%3Aopen%20label%3A%22good%20first%20issue%22) and discuss the scope on the issue. If none are available, propose a small task below.

## Quick links

- Issues: [Good first issue](https://github.com/larai-w/veai-line-message/issues/new?template=good-first-issue.yml)
- Pull requests: [Compare changes](https://github.com/larai-w/veai-line-message/compare)

Run `npm test` for handler changes. Tests use mocks; real LINE credentials are not needed.

## Check before PR

```bash
python3 scripts/check_public_repo.py --staged
```

Keep commit messages and PR descriptions factual and neutral.
